# 药-03 · 抗寄生虫药（伴侣动物，体外 / 体内外同驱）

> 驱虫药使用前应确认动物年龄、体重与寄生种类；外用滴剂不得内服。

## 3.1 氟雷拉纳咀嚼片（Fluralaner，犬）

- **类别**：异噁唑啉类杀虫杀螨剂（全身性抗寄生虫药）。
- **物种 / 剂型规格**：犬；咀嚼片 112.5 mg / 250 mg；口服（PO），可混入犬粮饲喂。

**适应证**：治疗犬体表跳蚤（猫栉首蚤）和蜱虫（长角血蜱、血红扇头蜱）感染。

**用法用量**（内服，按体重给药，每 12 周 1 次；治疗血红扇头蜱感染每 8 周 1 次；不可掰开或碾碎）：

| 体重（kg）        | 规格（mg/片） | 片数  |
| ------------- | -------- | --- |
| 2 ≤ 体重 ≤ 4.5  | 112.5    | 1   |
| 4.5 < 体重 ≤ 10 | 250      | 1   |
| 10 < 体重 ≤ 20  | 250      | 2   |
| 20 < 体重 ≤ 40  | 250      | 4   |

**不良反应**：个别犬（1.6%）出现轻微短暂胃肠道反应——腹泻、呕吐、食欲不振、流涎；极罕见（<1/10000）嗜睡和神经症状（抽搐、共济失调、肌肉震颤）。多数不良反应具自限性、持续时间短暂。

**注意事项**：

- 8 周龄以下幼犬和 / 或体重低于 2 kg 的犬不得使用。
- 对本品过敏的犬禁用；有癫痫病史的犬慎用。
- 给药间隔不得少于 8 周；可用于种犬、妊娠期和哺乳期母犬。
- 血浆蛋白结合率高，可能与其他高蛋白结合率药物竞争血浆蛋白；体外孵育试验未发现与卡洛芬、华法林竞争结合。
- 起效快，可降低虫媒病传播风险；但跳蚤和蜱须接触宿主并开始进食才接触到药物成分，恶劣条件下不能完全排除虫媒疾病传播风险。
- 给药时观察犬只确认吞下；施药人员不得进食、吸烟、饮酒，接触后肥皂清水彻底洗手；避免儿童接触。

**贮藏**：30℃ 以下密封保存。

## 3.2 氟雷拉纳滴剂（Fluralaner，猫）

- **类别**：异噁唑啉类外用杀虫杀螨剂。
- **物种 / 剂型规格**：猫；滴剂 0.4 mL : 112.5 mg；0.89 mL : 250 mg；外用（滴于猫头骨底部皮肤），不得内服。

**适应证**：治疗猫体表跳蚤（猫栉首蚤）和耳螨感染。

**用法用量**：

- 以氟雷拉纳计，**≥40 mg/kg**；将本品滴于猫头骨底部皮肤，**每 12 周 1 次**。
- 体重 ≤6.25 kg 涂一处；>6.25 kg 涂两处。

| 体重（kg）           | 规格                | 数量  |
| ---------------- | ----------------- | --- |
| 1.2 ≤ 体重 ≤ 2.8   | 0.4 mL : 112.5 mg | 1   |
| 2.8 < 体重 ≤ 6.25  | 0.89 mL : 250 mg  | 1   |
| 6.25 < 体重 ≤ 12.5 | 0.89 mL : 250 mg  | 2   |
| 体重 > 12.5        | 选择合适规格组合使用        | —   |

**不良反应**：个别猫给药部位轻度一过性皮肤反应——红斑和瘙痒（2.2%）；倦怠 / 震颤 / 厌食 0.9%；呕吐 / 唾液分泌过多 0.4%；抽搐反应 <0.01%。

**注意事项**：

- 缺乏相关数据，**小于 11 周龄或体重低于 1.2 kg 的猫不得使用**。
- 外用不得内服；避免给药猫之间互相舔梳被毛；过敏猫禁用；有神经系统病史的猫谨慎使用。
- 给药间隔不得低于 8 周；妊娠期和哺乳期猫安全性尚未研究，建议兽医评估后决定。
- 不得滴于皮肤破损处，避免与猫眼睛接触；施药戴一次性防护手套，皮肤敏感者避免接触给药部位。
- 本品对水生无脊椎动物有毒，未使用产品不应弃入下水道及水道。

## 3.3 塞拉菌素（Selamectin，外用滴剂）

> **药物节点**：`selamectin`
> **通用名**：塞拉菌素（Selamectin）｜商品名：Revolution、Stronghold｜归属分册：药-03
> **适应证要点**：犬猫跳蚤、耳螨、疥螨、心丝虫及部分肠道线虫预防与治疗
> **关联手册章节**：册-02·外寄生虫与螨病


- **类别**：大环内酯类（阿维菌素）内外同驱外用滴剂。
- **物种 / 剂型**：犬 ≥6 周龄；猫 ≥8 周龄；单支外用滴剂；外用（皮肤滴剂）。

**适应证**：

- **犬**：杀灭成年跳蚤并阻止跳蚤卵孵化达 1 个月；预防和控制跳蚤（猫栉首蚤）；预防心丝虫病（犬恶丝虫 *Dirofilaria immitis*）；治疗和控制耳螨（*Otodectes cynotis*）；治疗和控制疥螨（*Sarcoptes scabiei*）；控制变异革蜱（*Dermacentor variabilis*）。
- **猫**：杀灭成年跳蚤并阻止跳蚤卵孵化达 1 个月；预防和控制跳蚤；预防心丝虫病；治疗和控制耳螨；治疗和控制蛔虫（*Toxocara cati*）与肠道钩虫（*Ancylostoma tubaeforme*）。

**用法用量**：最低剂量 **2.7 mg/lb（6 mg/kg）**；整支滴于皮肤；体重 >130 lb 的犬使用两支组合。

**注意事项**：

- 给药前犬应检测是否已存在心丝虫感染；已感染犬由兽医决定是否先驱杀成虫。
- 塞拉菌素**对犬恶丝虫成虫无效**，也不能清除微丝蚴。

**不良反应**：约 1% 的用药猫在给药部位或附近出现一过性局部脱毛（伴或不伴炎症）；其余体征（≤0.5%）：呕吐、稀便 / 腹泻（可带血）、厌食、嗜睡、流涎、呼吸急促、肌肉震颤。
