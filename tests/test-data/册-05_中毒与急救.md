# 册-05 · 中毒防范与现场急救（犬猫）

## 5.1 中毒应急原则

- 已知或怀疑吞入 / 接触有害物质：立即联系兽医、当地急诊动物医院或中毒控制热线。
- 备好产品 / 包装以供核对；收集呕吐物或被咬食的残留物，密封塑料袋中带到医院。
- **未经兽医或中毒控制中心指导，不要自行催吐或给动物用药。**

## 5.2 常见现场处置流程

### 出血

- 用干净布或毛巾在出血部位直接压迫止血。
- 至少压迫 3 分钟内不要揭开查看是否止血。
- 出血严重立即送医；血渗透毛巾时不要取下原毛巾，在其上叠加毛巾，避免破坏可能形成的血凝块。

### 热射病（中暑）

- 体征：呼吸急促 / 大口喘息、大量流涎、虚弱或嗜睡、意识混乱、呕吐或腹泻、牙龈颜色异常、干燥或发黏。
- 尽快送医并同时开始降温：移至阴凉或舒适凉爽的室内；用室温水浸湿毛巾敷于颈部、腋下、腹股沟，数分钟更换；有风扇可直吹。
- **不要将动物浸入凉 / 冷水浴**，可能使病情加重。

### 意识丧失且无呼吸

- 张口、轻握舌头向前拉出使舌尖露出口外；快速检查口咽有无异物阻塞气道。
- 闭口后经鼻吹气进行人工呼吸，见胸廓扩张为止；胸廓扩张后以 **10 次/分钟** 频率持续，直至自主呼吸或送达医院。

### 同时无心跳（CPR）

- 先按上述人工呼吸，再摆放体位开始胸外按压：
  - 猫与多数犬：侧卧；桶状胸犬（如英斗）：仰卧。
  - 小型犬与猫：单手环绕胸底部，拇指与其余手指挤压胸部，**100–120 次/分钟**。
  - 桶状胸犬：双手掌重叠于胸骨中段；其他犬：掌根重叠于胸部最宽处，灵缇 / 杜宾等深胸犬置于腋后；双肘锁定，100–120 次/分钟。
  - 侧卧按压深度约胸宽 1/3–1/2；仰卧约 1/4。
- 单人：30 次按压后给予 2 次人工呼吸，循环进行；双人：一人按压、一人以 10 次/分钟给人工呼吸；头颈与脊柱保持一线以免气道受阻。
- 持续至可触及 / 听到心跳并规律呼吸，或送达医院由接诊方接管。

### 抽搐发作

- 清理周围其他宠物、家具与可致伤物件。
- 不要按压约束或试图惊吓终止发作；不要将手指 / 手放入其口内。
- 尽量计时并录像，供兽医参考；发作停止后保持安静，联系兽医或急诊医院。

### 外伤与搬运

- 如安全可行，包扎或夹板固定伤处再搬动；把握不足时交由兽医处理（不当包扎 / 夹板可能加重伤害）。
- 伤口内异物不要拔出；必要时修剪异物外露部分、保留 3–6 英寸外露，再就医。
- 搬运时置于狭小空间（航空箱、纸箱，保证通气）减少二次伤害；大型犬用平板、雪橇或毛毯作担架。

### 异物窒息

- 仍能呼吸：保持安静，立即就医；在不造成伤害前提下张口检查异物。
- 可见异物：双手张口后小心取出；必要时用勺柄平面将异物拨近，避免推入更深处。
- 猫与小型犬：手指无法取出时，提起后腿悬空左右摆动；无效则在肋骨后缘腹部向前施压。
- 大型犬：站位可参照人用海姆立克法，拳置于肋弓下软处向上向前；侧卧时一手扶背、另一手向上挤压腹部。

## 5.3 灭鼠药（抗凝血剂）中毒解毒

- 抗凝血灭鼠药 / 双香豆素中毒以维生素 K1（叶绿醌）为基础解毒；二代灭鼠药疗程更长；新凝血因子合成需 6–12 小时，重症可能需配合血浆制品。

## 5.4 施救者安全提示

- 受伤动物因疼痛与恐惧可能不可预测，避免拥抱；面部避开其口部；有咬击威胁时佩戴口套（呕吐时不要套口套）；尽量请他人协助搬运。

## 5.5 急救箱基本物品

紧急电话与病历 / 用药记录、体温计、口套、备用牵引绳与项圈、纱布卷、清洁毛巾、不粘绷带 / 干净布条、自粘不粘胶带、医用胶带、圆头剪刀、一次性手套、小手电、镊子、滴管 / 无针大注射器、无菌润滑胶、活性炭（仅在兽医 / 中毒中心指导下使用）、3% 过氧化氢（催吐用，须先联系兽医 / 中毒中心，未经指导不得超过一次剂量，不得用于伤口）、生理盐水（伤口 / 眼部冲洗）。
