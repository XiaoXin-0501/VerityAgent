# 册-02 · 皮肤与耳疾病与用药路径（犬猫）

## 2.1 浅表 / 深部脓皮病（细菌性皮肤感染）

**常见症状**
- 丘疹、脓疱、痂皮、脱毛、表皮剥脱；瘙痒程度不一；深部感染可见结节、瘘管、排脓与蜂窝织炎。

**常见病因**
- 多继发于跳蚤过敏、特应性皮炎、寄生虫、内分泌疾病或异物；犬常见伪中间葡萄球菌产 β-内酰胺酶，经验性方案应覆盖产酶株。

**处理原则**
- 先控制原发病（过敏原、寄生虫、内分泌异常）；局部药浴配合全身抗菌；深部感染须足够疗程并复查。
- 不建议单用非处方软膏或含激素局部制剂；经验性避免青霉素、氨苄西林、阿莫西林等不耐受产酶株的药物。

**涉及药物**
- 局部药浴：洗必泰、过氧化苯甲酰、洗必泰-咪康唑、次氯酸钠等外用制剂。
- 全身抗菌：克林霉素、头孢氨苄、阿莫西林克拉维酸等。

**相关药物**：〔药-01·恩诺沙星 `enrofloxacin`〕、〔药-01·马波沙星 `marbofloxacin`〕、〔药-01·阿莫西林克拉维酸钾 `amoxicillin-clavulanate`〕、〔药-01·头孢氨苄 `cephalexin`〕、〔药-01·头孢泊肟酯 `cefpodoxime`〕、〔药-01·克林霉素 `clindamycin`〕
## 2.2 外寄生虫与螨病（疥螨、蠕形螨、跳蚤等）

**常见症状**
- 剧烈瘙痒、脱毛、红斑、痂皮、抓咬；疥螨多累及耳缘、肘跗、腹侧；蠕形螨可见局灶或全身脱毛、红斑、脓皮病。

**处理原则**
- 先皮肤刮片或显微镜检查确认虫种；环境驱虫与同群动物同时处理。
- 蠕形螨禁用局部或全身糖皮质激素；治疗需持续至连续两次（间隔 1 个月）刮片阴性。伊维菌素等大环内酯类用药前应考虑 MDR1/ABCB1 基因检测，敏感品种禁用。

**涉及药物**
- 外用药与口服驱虫：塞拉菌素、吡虫啉-莫昔克丁、米尔贝肟、伊维菌素、异噁唑啉类（氟雷拉纳等）。

**相关药物**：〔药-03·塞拉菌素 `selamectin`〕、〔药-03·沙罗拉纳 `sarolaner`〕、〔药-03·多杀菌素 `spinosad`〕
## 2.3 皮肤癣菌病（猫癣 / 犬癣，人畜共患）

**常见症状**
- 圆形或不规则脱毛、鳞屑、痂皮、红斑、丘疹、色素沉着，瘙痒程度不定；犬可出现结节性脓癣（kerion），猫可见甲周炎。

**常见病原**
- 犬小孢子菌、须毛癣菌、石膏样小孢子菌等；为人畜共患病，患病动物在临床与真菌学治愈前应与其他易感动物及人群隔离。

**处理原则**
- 局部药浴消毒被毛、清除环境孢子；全身抗真菌杀灭毛囊内感染；疗程须持续到真菌学治愈（培养或 PCR 阴性），通常整体 6–12 周。
- 酮康唑禁用于猫（可致厌食）；氟康唑对癣菌效果差不建议使用；灰黄霉素与虱虱脲不推荐；复方伊曲康唑生物利用度差，应使用市售兽用液体剂型。

**涉及药物**
- 全身抗真菌：伊曲康唑、酮康唑（犬）、特比萘芬。
- 局部药浴：石灰硫磺、恩康唑、洗必泰-咪康唑香波。

## 2.4 特应性皮炎 / 慢性瘙痒

**常见症状**
- 反复瘙痒、抓咬、舔舐；耳、足、腹侧、腋下多见；继发跳蚤过敏、食物不良反应或脓皮病时症状加重。

**处理原则**
- 先排除跳蚤、寄生虫、食物不良反应与感染；控制继发感染后再长期管理瘙痒。
- 长期方案以规避过敏原、抗炎止痒与皮肤屏障维护为主；糖皮质激素仅作短期诱导，不建议长期维持。

**涉及药物**
- 全身抗炎止痒：糖皮质激素、环孢素、奥拉替尼、IL-31 单克隆抗体（lokivetmab）、JAK 抑制剂等。
- 局部：他克莫司软膏、曲安奈德局部制剂。
- 继发感染：抗菌与抗真菌局部 / 全身用药。

**相关药物**：〔药-02·卡洛芬 `carprofen`〕、〔药-07·奥拉替尼 `oclacitinib`〕、〔药-07·环孢素 `cyclosporine`〕
## 2.5 外耳炎

**常见症状**
- 摇头、抓耳、耳道分泌物、异味、耳廓红肿疼痛；反复发作提示异物、过敏、寄生虫或内分泌基础病。

**处理原则**
- 先清洁并检查耳道（异物、增生、穿孔）；镜检分泌物确定细菌 / 真菌 / 螨虫；鼓膜穿孔时避免刺激性滴耳剂。
- 反复发作者必须控制原发过敏或寄生虫；疗程按复查结果调整，不长期依赖含激素的复方滴耳剂。

**涉及药物**
- 局部清洁与抗真菌 / 抗菌滴耳：洗必泰、咪康唑 / 克霉唑 / 酮康唑复方等。
- 螨虫驱虫；重症或全身感染时全身用抗菌药。
