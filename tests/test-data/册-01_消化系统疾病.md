# 册-01 · 消化系统疾病与用药路径（犬猫）

## 1.1 呕吐 / 急性胃炎

**常见症状**
- 呕吐（单次或反复）、腹部不适、食欲下降、沉郁，可伴脱水。
- 呕血、咖啡渣样呕吐物、黑便、明显腹痛、持续不进食或精神极差，提示溃疡、异物、胰腺炎或代谢性疾病，须尽快就医。

**可能病因**
- 饮食不当、误食异物、感染、药物刺激、应激；继发于胰腺炎、肾病、肝病、胃肠道溃疡或阻塞等。

**处理原则**
- 评估脱水与电解质，必要时补液；短暂禁食后渐进恢复少量易消化食物。
- 排查异物、溃疡与代谢性病因；不建议在病因未明前自行长期止吐掩盖症状。

**涉及药物**
- 止吐药：马罗匹坦；其他止吐方案按医嘱。
- 持续呕吐、无法进水或怀疑梗阻时，以住院评估与静脉支持为主，不按家庭方案处理。

**相关药物**：〔药-05·马罗匹坦 `maropitant`〕、〔药-05·米氮平 `mirtazapine`〕
## 1.2 慢性腹泻 / 慢性肠病

**常见症状**
- 腹泻、呕吐、食欲改变、体重减轻，持续或间歇超过 3 周；可见大肠性腹泻、黏液便或血便。
- 蛋白丢失性肠病可伴腹水、外周水肿；部分病例胃肠症状轻微。

**可能分型**
- 食物反应型、抗菌药反应型、免疫抑制反应型、无反应型；蛋白丢失性肠病为另一类，预后更谨慎。

**处理顺序**
1. 先做驱虫 / 抗寄生虫处理。
2. 换用低敏饮食（水解蛋白或新型蛋白），单独饲喂至少 2 周观察反应；多数食物反应型在 2 周内见效。
3. 饮食无效且病情稳定者，可考虑抗菌药试验；仍无效则内镜或手术活检，再决定免疫抑制治疗。

**涉及药物**
- 抗菌药试验：泰乐菌素、甲硝唑等（手册参考，超说明书）。
- 免疫抑制：糖皮质激素、环孢素、硫唑嘌呤、苯丁酸氮芥。
- 大肠受累：柳氮磺吡啶及其衍生物。
- 低钴胺素血症补充维生素 B12。

## 1.3 结肠炎（大肠性腹泻）

**常见症状**
- 黏液便、便血、里急后重、排便急迫、单次便量减少；排便疼痛；体重减轻与呕吐较少见，多在小肠受累时出现。症状可时轻时重、反复波动。

**可能病因**
- 细菌、寄生虫、真菌等感染；食物过敏；炎性肠病；鞭虫、贾第虫、三毛滴虫等寄生虫；犬肉芽肿性结肠炎（Boxer、法国斗牛犬）；艰难梭菌相关伪膜性结肠炎。

**处理原则**
- 先排查感染与寄生虫；稳定病例先做饮食试验（高纤维、易消化或低敏饮食，至少 2 周单独饲喂）。
- 饮食与驱虫无效、活检证实炎症者，再用抗炎 / 免疫抑制治疗；可辅以益生菌、益生元或粪菌移植调节菌群。

**涉及药物**
- 驱虫：芬苯达唑等。
- 抗菌 / 抗原虫：甲硝唑、泰乐菌素、恩诺沙星（肉芽肿性结肠炎，犬）。
- 抗炎 / 免疫抑制：糖皮质激素、硫唑嘌呤（犬）、苯丁酸氮芥（猫）、环孢素。
- 大肠抗炎：柳氮磺吡啶、奥拉沙拉嗪、美沙拉嗪（犬；猫不建议柳氮磺吡啶）。
- 止泻：洛哌丁胺（感染性结肠炎禁用；ABCB1 突变犬慎用）。

## 1.4 胃肠感染（细菌 / 寄生虫 / 病毒）

**常见症状**
- 腹泻、呕吐、脱水、食欲下降；病毒性感染（如细小病毒）可急性起病、发热、血便，幼犬风险更高。

**处理原则**
- 支持疗法：口服或胃肠外补液纠正脱水与电解质、营养支持、止吐、益生菌帮助恢复肠道菌群。
- 细菌性感染依据诊断选用抗菌药；寄生虫感染用驱虫药；多数病毒感染无特异性治疗，以支持护理为主。
- 不推荐把抗菌药作为非特异一线用药；优先采用益生菌、益生元与饮食调整，抗菌药仅用于无反应或有败血症风险的重症。

**相关药物**：〔药-01·恩诺沙星 `enrofloxacin`〕、〔药-01·阿莫西林克拉维酸钾 `amoxicillin-clavulanate`〕
## 1.5 胃肠溃疡

**常见症状**
- 呕吐、厌食、腹痛、体重减轻；呕血与黑便表现不定，猫常缺乏特异表现。
- 严重溃疡或穿孔可见疼痛、虚弱、苍白、休克或败血症表现。

**常见病因**
- NSAID 使用、肿瘤、肝病最常见；外伤、肾病、肾上腺皮质功能减退、胰腺炎、全身炎症等也可诱发。
- **NSAID 与糖皮质激素联用会显著增加溃疡风险，属禁忌**；即使是选择性 COX-2 抑制剂也仍可能发生溃疡穿孔。

**处理原则**
- 首先去除并治疗病因（如停用 NSAID）；纠正代谢紊乱与补液；抑酸与黏膜保护促进愈合；穿孔或药物治疗无效者需手术。
- 抗溃疡疗程通常约 4–6 周；长期用药者停药应逐步减量，避免反跳性胃酸过多。

**涉及药物**
- 质子泵抑制剂（奥美拉唑、泮托拉唑）、H2 阻断剂（法莫替丁）、黏膜保护剂（硫糖铝）、前列腺素类似物（米索前列醇）。

## 1.6 胰腺炎

**常见症状**
- 犬猫均可发生，可无症状或表现为呕吐、腹痛、厌食、沉郁、脱水；猫常合并肝病与小肠疾病（三体炎）。重症可出现休克、多器官并发症。

**常见风险因素**
- 犬：饮食不当、严重高甘油三酯血症、库欣综合征、外伤、部分药物；猫：寄生虫感染、慢性肠病与胆管肝炎并发。

**处理原则**
- 识别并处理基础病因与风险因素；重症以补液支持、严密监护、早期防治全身并发症为主。
- 犬予低脂饮食（<20 g 脂肪/1000 kcal），猫中等限脂；呕吐动物止吐，腹痛镇痛；慢性病例无改善可尝试免疫抑制治疗。
- 抗菌药价值有限，不常规使用；常规禁食仅在止吐治疗后仍频繁剧烈呕吐时短期采用，早期肠内营养优于全胃肠外营养。

**涉及药物**
- 止吐：马罗匹坦、昂丹司琼等。
- 镇痛：阿片类（布托啡诺、丁丙诺啡、哌替啶、吗啡 / 芬太尼 / 美沙酮 CRI 等）。
- 促食欲：卡普拉莫林、米氮平。
- 慢性病例免疫抑制尝试：泼尼松 / 泼尼松龙、环孢素。
- 犬急性胰腺炎专用生物制剂（fuzapladib sodium）为条件批准用药，须兽医评估。

## 1.7 肝胆疾病

**常见症状**
- 黄疸、黏膜黄染、尿色加深；食欲下降、呕吐、消瘦、腹水；肝酶与胆红素升高。可由病毒、细菌、真菌、原虫感染，脓毒症相关胆汁淤积，药物 / 毒素性肝损伤，免疫介导性或铜代谢异常引起。

**处理原则**
- 先经化验、影像，必要时活检、PCR / 培养明确病因；钩端螺旋体、分枝杆菌等人畜共患病须做好接触与尿液防护。
- 按病原选用抗菌或抗原虫治疗；脓毒症相关胆汁淤积以控制感染、纠正低血压与缺氧为主。
- 支持补液、纠正低血糖与电解质紊乱；肝保护与抗氧化作为辅助；免疫介导性肝病须在充分排除感染后再行免疫调节。

**涉及药物**
- 抗菌：氨苄西林 / 阿莫西林、多西环素、甲硝唑、恩诺沙星、克林霉素；分枝杆菌：利福平、普拉多沙星、阿奇霉素。
- 抗原虫：克林霉素（弓形虫）、别嘌醇、锑剂、两性霉素 B（利什曼）。
- 肝保护辅助：SAMe、维生素 E、磷脂酰胆碱、N-乙酰半胱氨酸。

### 什么是牙菌斑？

|牙菌斑是由食物残渣、细菌、唾液和死细胞共同构成，持续附着在动物牙齿表面的薄膜。如果牙菌斑存在超过 72 小时，就会逐渐开始硬化形成一种称为牙垢（牙结石）的物质，并堆积在牙齿的根部（牙龈线附近）。这种堆积会刺激牙龈，从而促进牙龈疾病的发生。|
